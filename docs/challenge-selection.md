# Challenge selection

Use the official brief and sample data to choose the problem. Public company
announcements are leads, not substitutes for the actual judging criteria.

## Questions for a candidate challenge

- Is usable sample data accessible now?
- What is the intended user and outcome?
- What target, labels, or independent evaluation evidence is available?
- What baseline can be produced within 90 minutes of choosing?
- What are the data, model, AI-assistant, and publication rules?
- Does the compute and integration effort fit solo execution?
- Which outputs and metrics matter to the judges?
- Can the same project enter compatible additional challenges?

## Selected problem

Primary challenge, mentor notes, dataset access, metric, baseline, minimum demo,
and reasons for choosing: to be recorded after the official briefs are reviewed.

If data access remains blocked, move to the next viable candidate before investing
in integration. Target the preliminary draft by Friday 23:45 Helsinki time.
