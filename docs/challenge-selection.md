# Selected challenge

WikiLens targets the **MariaDB RAG** part of the user-supplied “Wikipedia Through Time” challenge brief for Junction 2026. The source brief was reviewed before the model and pipeline work. The full dashboard paste is not published because it includes unrelated account information.

The challenge asks for a useful experience on Wikipedia data with MariaDB central to the implementation. The five judging dimensions are equally weighted: MariaDB use, implementation, usefulness, demonstration/design and originality. The chosen deliverable is a working retrieval–generation pipeline with source inspection and measured performance over the complete provided Finnish corpus.

The pitch therefore leads with native vector retrieval, passage selection, generation, review and inspectable evidence. Context disambiguation demonstrates source selection; it is not the entire project. System-versioned tables/time travel belong to another capability and are not implemented or claimed here.
