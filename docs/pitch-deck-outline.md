# Pitch deck outline

Create the final PDF after the challenge, method, and measured result are established.

## Slide 1 Project and user problem

Project name, punchline, intended user, and the concrete problem.

## Slide 2 Challenge and data

Selected challenge, dataset, important constraints, and why the problem matters.

## Slide 3 Method

Baseline, selected approach, and a simple explanation of the main technical choice.

## Slide 4 Demonstration

One representative input and output. Use a screenshot or plot that matches the demo.

## Slide 5 Evidence and limitations

Measured results against the baseline, evaluation split, failure cases, and limits.
Use actual observed numbers and distinguish any untested hypotheses.

## Slide 6 Impact and next step

User benefit, realistic next step, project author, demo link, and source link.

## Export checks

- [ ] All placeholders replaced with the final project.
- [ ] Every plotted value and metric agrees with saved experiment results.
- [ ] PDF export inspected slide by slide.
